# SAFIZ MARKETING

Property discovery marketplace built with Next.js App Router, TypeScript and Tailwind CSS. Fonts: Bodoni Moda for selective display headings, Manrope for UI and numeric data.

## Development

- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- `npm run start`

## Content

`src/types/marketplace.ts` defines Developer, Project, PropertyUnit and Media. `src/data/marketplace.ts` supplies the local catalogue and relationship queries. Components consume this data rather than embedding project records. `src/lib/marketplace-search.ts` implements URL-driven city, property type, project, developer, bedroom, price, keyword and sort filters.

## Production / Vercel

Connect the GitHub repository to Vercel as a Next.js project with production branch `main`. Use the standard `npm run build` build command. No database, mail credentials or private environment variables are required by the current implementation.

`NEXT_PUBLIC_SITE_URL` configures the production HTTPS origin; `.env.example` documents it. The safe default is `https://marketing.safiz.pk`. Localhost and Vercel preview origins are excluded from canonicals. Vercel preview builds are noindex; production remains crawlable.

Metadata, Open Graph, Twitter cards and structured data are centralized in `src/lib/site.ts` and `src/lib/seo.ts`. The approved sharing image is `public/images/og/safizmarketing-og.jpg` (1200 × 630). The sitemap includes all local project, developer and unit records.

After connecting the deployment and custom domain, verify `/robots.txt`, `/sitemap.xml` and `/images/og/safizmarketing-og.jpg` on the live HTTPS domain. Source references and temporary visual QA output are local working material and are excluded from Git; all runtime assets are included under `public/`.
